# Отключение горячей воды в Москве для Home Assistant

Кастомная интеграция Home Assistant, которая получает официальный график планового отключения горячей воды с mos.ru.

## Установка через HACS

1. Добавьте `https://github.com/MrKerson/moscow-hot-water-ha` в HACS как пользовательский репозиторий типа **Integration**.
2. Установите интеграцию и перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию**.
4. Найдите **Отключение горячей воды в Москве**.
5. Введите адрес и выберите найденный вариант.
